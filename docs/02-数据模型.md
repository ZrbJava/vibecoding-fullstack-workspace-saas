## 初始数据模型概览

> 这里先只写最小可运行所需的核心表，后续会在实现各阶段功能时逐步补充和调整。

### User 用户表（当前版本）

- `id`：主键，字符串（cuid）
- `email`：唯一邮箱
- `passwordHash`：密码哈希（使用 argon2 生成）
- `name`：可选昵称
- `createdAt`：创建时间
- `updatedAt`：更新时间

该表当前用于支持用户注册/登录流程，后续会在此基础上增加更多 profile 字段与登录审计信息。

### 后续规划（暂不建表，仅规划）

- Workspace 相关：`workspaces`、`workspace_members`、`roles`、`permissions`
- 任务相关：`projects`、`tasks`、`task_comments`、`task_labels`
- 知识库相关：`documents`、`document_tree`
- 文件相关：`files`（元数据，与对象存储路径关联）
- 审计日志相关：`audit_logs`

## Workspace 相关模型（当前版本）

### Workspace 表

- `id`：主键，字符串（cuid）
- `name`：空间名称
- `description`：空间描述（可选）
- `ownerId`：拥有者用户 ID（外键关联 `User.id`）
- `createdAt`：创建时间
- `updatedAt`：更新时间

### WorkspaceMember 表

- `id`：主键，字符串（cuid）
- `userId`：成员用户 ID（外键关联 `User.id`）
- `workspaceId`：所属 Workspace ID（外键关联 `Workspace.id`）
- `role`：角色（枚举 `WorkspaceRole`：`OWNER` / `ADMIN` / `MEMBER`）
- `createdAt`：创建时间

- 约束：
  - `@@unique([userId, workspaceId])`：一个用户在同一个 workspace 中只能出现一次。

在实现过程中，每当我们为某一模块增加/修改数据模型时，会回到本文件补充具体字段和关系说明。
