## 项目概览

- **项目名称**：Vibecoding 全栈训练项目
- **目标**：从前端工程师成长为能够独立完成后端开发与云部署的全栈工程师，最终产出一个可在线访问的生产级小型 SaaS 应用（团队任务 & 知识库）。
- **技术栈**：
  - 后端：Node.js + TypeScript + NestJS + Prisma + PostgreSQL + Redis
  - 前端：React + Vite + TypeScript
  - 运维：Docker + docker compose + Nginx + Let’s Encrypt + GitHub Actions（后期）

## 范围与非目标

- **范围**：
  - 账号体系（注册/登录/鉴权）
  - Workspace 多租户与 RBAC 权限
  - 任务管理与看板视图
  - 知识库（文档树）与搜索
  - 文件上传与访问控制
  - 审计日志与基础统计
  - 云服务器部署与基础 CI/CD
- **非目标（暂不覆盖）**：
  - 大规模高并发、高可用集群架构
  - 非核心业务的复杂可视化与 BI 分析

## 时间规划（可调整）

- 总周期：约 8–12 周（每周 5–10 小时）
- 阶段划分（对应实现与学习重点）：
  - 阶段 0：初始化与基础设施
  - 阶段 1：用户与鉴权模块
  - 阶段 2：Workspace + RBAC + 基础任务
  - 阶段 3：知识库、搜索与文件上传
  - 阶段 4：审计日志、基础统计与优化
  - 阶段 5：云服务器部署与 HTTPS
  - 阶段 6：CI/CD 与质量提升（可选）
