## 安全清单（初稿）

> 目前仅有公开健康检查接口，安全风险较低。随着鉴权与更多业务功能的实现，本清单会逐步细化。

### 认证与授权（规划）

- 使用 JWT（访问令牌 + 刷新令牌）进行认证。
- 统一在后端通过 Guard 中间件进行权限校验。
- 对敏感操作（删除、修改权限等）进行严格的 RBAC 控制。

### 数据安全（规划）

- 用户密码只存储哈希（argon2 或 bcrypt），绝不明文保存。
- 数据库访问通过 Prisma，避免 SQL 注入。
- 为关键表和查询添加适当索引，避免全表扫描带来的性能与安全问题。

### 输入与输出安全（规划）

- 所有外部输入在进入业务逻辑前进行校验与类型转换。
- 前端对富文本/Markdown 渲染进行 XSS 防护处理。

### 配置与密钥管理（规划）

- 使用环境变量存储敏感配置（数据库密码、JWT 密钥等），不提交到代码仓库。
- 在 CI/CD 中通过 Secret 管理敏感信息。
