## 开发环境部署手册（初稿）

### 环境要求

- Node.js >= 18
- npm 或 pnpm/yarn
- Docker 与 docker compose（后续用于本地与服务器部署）

### 本地启动步骤（初版）

1. 克隆仓库并进入项目根目录。
2. 安装依赖：
   - 后端：进入 `backend/` 目录，执行 `npm install`。
   - 前端：进入 `frontend/` 目录，执行 `npm install`。
3. 启动后端（开发模式）：
   - 在 `backend/` 中执行：`npm run start:dev`。
4. 启动前端（开发模式）：
   - 在 `frontend/` 中执行：`npm run dev`。
5. 在浏览器中访问：
   - 前端入口：`http://localhost:5173`
   - 后端健康检查（被前端代理）：`/api/health`

后续我们会在本文件中补充：本地 Docker 编排、云服务器部署、Nginx 反代与 HTTPS 等章节。
